# What Meme Mod for Minecraft 1.21

![icon](https://github.com/user-attachments/assets/7c8e862a-03b5-49ad-99a1-e0ab59c4ba94)


## 简介

What Meme 是一个为 Minecraft 1.21 版本开发的趣味模组，灵感来源于经典的 "What" 表情包。该模组允许玩家在游戏中通过指令或快捷键触发一个特殊的 "What" 动画界面，并伴有标志性的音效。

## 功能特性

- 🎭 通过指令 `/what` 或 `/wt` 触发 What 动画
- 🎮 支持快捷键（默认：H）快速打开 What 界面
- 🔊 内置经典 What 音效
- ~~⏱️ 可自定义动画持续时间~~
- 🎨 简洁美观的 GUI 界面
- 🌍 支持多语言（目前支持英文和简体中文）

## 安装指南

1. 确保已安装 Minecraft 1.21 和 Fabric Loader
2. 下载最新版本的 What Meme mod
3. 将 mod 文件放入 `mods` 文件夹
4. 启动游戏并享受！

## 使用说明

### 指令使用

- 基本指令：`/what <玩家> <持续时间>`
  - 示例：`/what @a 5` （对所有玩家显示5秒动画）
- 快捷指令：`/wt <玩家> <持续时间>`

### 快捷键

- 默认快捷键：`H`
- 可在控制设置中自定义快捷键
